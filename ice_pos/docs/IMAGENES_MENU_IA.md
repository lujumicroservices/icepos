# Imágenes del menú para generar con IA

Usa esta lista para pedir a una IA (DALL·E, Midjourney, Ideogram, Canva, etc.) que genere las imágenes. **El nombre del archivo debe ser exactamente el indicado** (sin acentos, minúsculas, espacios = guión bajo) para que la app pueda asociarlas al producto.

Formato sugerido al guardar: `NOMBRE.png` o `NOMBRE.jpg` (ej. `baguette.png`).

---

## Categoría: Baguettes y similares

| Nombre del archivo | Descripción para pedir a la IA |
|--------------------|--------------------------------|
| `baguette` | Baguette o pan francés recién horneado, rebanado por la mitad, relleno visible (jamón, queso o vegetales), estilo sándwich gourmet, fondo neutro, foto apetitosa |
| `croissant_jamon_queso` | Croissant relleno de jamón y queso, dorado, hornado, estilo café, fondo claro |
| `croissant_nutella` | Croissant relleno de Nutella o chocolate, espolvoreado, estilo repostería, fondo neutro |

## Ejemplo de prompt completo para una IA

Puedes usar un prompt base y sustituir la descripción:

> "Fotografía de producto para menú de cafetería/heladería: [DESCRIPCIÓN DE LA TABLA]. Estilo realista, fondo blanco o neutro claro, iluminación suave, sin texto, formato cuadrado o 4:3."

Ejemplo para `malteada`:

> "Fotografía de producto para menú de cafetería: malteada espesa en vaso alto con crema batida y sorbete, sabor chocolate. Estilo realista, fondo blanco, iluminación suave, sin texto."
